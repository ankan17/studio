# Phase 0 spike results

Test machine: 8GB Apple Silicon (MacBook Air, M1, `MacBookAir10,1`), measured Nov 10 2026. Remotion 4.0.542, mediabunny 1.64.0.
Earlier figures came from a 24GB dev Mac and are kept below as "24GB:" notes. Rule: fill each block with figures, not impressions. Swap growth during a run is a fail.

Conditions on the 8GB run: other apps were open (not closed), and 0.8GB of swap was already in use and flat through every run (811MB to 811MB), so swap growth reads 0MB for every experiment. Run order matters: exp2 and exp3 need the proxies that exp6 writes to `spike/cache/`, so run exp6 on all clips first. Two earlier attempts at exp2 hung because the cache was empty (exp2 waits for a `*.proxy.mp4`).
All exp6 runs write to the same `exp6-result.json`, so only the last clip's summary survives; the per-run CSVs are kept.
